NS-FPS: Accelerating Farthest Point Sampling via Neighbor Search in Large-Scale Point Clouds
Jiapei Zheng*, Shuan Yang*, Siqi He, Qi Liu, Chixiao Chen
ISCA 2026

We propose NS-FPS, a hardware-software co-designed accelerator that transforms the FPS (Farthest Point Sampling) problem in point cloud processing into a neighbor search problem, reducing the complexity from O(N2) to (Nlog N).
